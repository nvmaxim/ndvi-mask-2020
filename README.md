# India NDVI Mask Processing

Инструмент для автоматического создания масок полей (GeoTIFF) на основе временных рядов NDVI. Используется для агромониторинга (рисовые поля, сезонные культуры).

> **Версия 2026 (Optimized):** В корне репозитория находится оптимизированная версия алгоритма (NumPy vectorization).  
> **Оригинальная версия (2020):** Доступна в папке [legacy/](./legacy/).
